# EduTrack

**Your Academic Journey, One Place.**

EduTrack is a Student Academic Management System being developed as a continuous web development learning project.

## Current Stage

Day 1–3 completed:
- Project planning
- User stories
- Basic HTML structure
- Semantic HTML
- Navigation links
- Student login form
- Academic results table
- Basic accessibility through labels

## Pages

- `index.html` — EduTrack homepage
- `login.html` — Student login page
- `results.html` — Student results page

## Main Users

- Students
- Lecturers
- Administrators

## Current Technologies

- HTML

More technologies will be added throughout the 60-Day Web Development Mastery Streak.

## Project Goal

Build a professional Student Academic Management System step by step, eventually adding CSS, JavaScript, APIs, React, backend development, database, authentication, testing, security and deployment.

## Important Learning Rule

Never commit code you cannot explain.
